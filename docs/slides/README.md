# Presentation: algebraic two-level Schwarz preconditioner

Beamer (metropolis theme), 16:9, 36 slides. Compile with **pdfLaTeX** (e.g. Overleaf, compiler pdfLaTeX),
twice, or `latexmk -pdf main.tex`. With XeLaTeX/LuaLaTeX metropolis switches to the Fira fonts and the
layout changes.

- `main.tex` – the slides
- `classmap.tex` – class map drawn once in TikZ; `\cmfocus{...}` selects the classes in colour,
  `\cmsection{x1}{y1}{x2}{y2}{width}` cuts a window of it, `\cmthumb` draws the mini-map of the title bar.
  Windows used by the slides: `\Wpart`, `\Wone`, `\Wlump`, ... at the top of `main.tex`.
- `grid_nodes.tex` – grid of the one-level slide (generated by `scripts/grid_tikz.py`)
- `fig/` – plots: `bubble_modes.png` (generated by `scripts/bubble_modes.py` from
  `matgen bubbles2d 128 nb=5 radius=0.08 seed=11`, and `rho=1`), the others copied from `test/*/` of the repository
